<h2 id="the-spirit">✦ The Spirit of the Game</h2>

<p>
  <strong>NAMMA RUNNER: Bengaluru Metro Rush</strong> is a browser-native, high-octane 3D endless runner set across the elevated viaducts and neon-lit subterranean tunnels of <strong>Namma Metro (BMRCL)</strong>. Built from scratch with <strong>Three.js</strong>, <strong>React 19</strong>, and <strong>procedural WebAudio synthesis</strong>, it fuses classic arcade lane-sprinting with unmistakable Bengaluru culture — bilingual English &amp; Kannada station signage, quirky skyline billboards, live Kannada/Kanglish voiceovers, dynamic monsoon track physics, and zero-download playability on both desktop and mobile.
</p>

<br />

<div align="center">
  <table>
    <tr>
      <td width="50%" valign="top">
        <h4>🟣 Elevated Skies to Neon Tunnels</h4>
        <p>
          Vault across oncoming Purple and Green Line trains above Bengaluru's skyline, then plunge seamlessly through tunnel portals into subterranean stations lit with electric violet strips and green exit beacons.
        </p>
      </td>
      <td width="50%" valign="top">
        <h4>🟡 Bilingual Bengaluru Identity</h4>
        <p>
          Every station marquee, voice-over callout, and skyline billboard celebrates the city in both <strong>English</strong> and <strong>ಕನ್ನಡ (Kannada)</strong> — complete with native <code>kn-IN</code> / <code>en-IN</code> Web Speech announcements and festive yellow-red viaduct pennants.
        </p>
      </td>
    </tr>
    <tr>
      <td width="50%" valign="top">
        <h4>🌧️ Living Monsoon Physics</h4>
        <p>
          Every 200 meters, Bengaluru's famously unpredictable sky shifts from golden sun to light drizzle to <strong>Heavy Monsoon</strong> — bringing slanted rain curtains and subtle wet-track hydroplane drift that rewards sharp timing.
        </p>
      </td>
      <td width="50%" valign="top">
        <h4>⚡ Bulletproof Dual-Engine Core</h4>
        <p>
          Boots into hardware-accelerated <strong>Three.js WebGL2</strong> with ACES Filmic tone mapping and procedural textures, and silently falls back to a bespoke <strong>2.5D Canvas2D</strong> renderer on constrained or software-GL devices.
        </p>
      </td>
    </tr>
  </table>

<h2 id="engineering">✦ Architecture &amp; Local Flavor Deep-Dives</h2>

<details>
  <summary><strong>🏛️ Codebase Architecture &amp; Module Map</strong> — <em>Clean separation between pure simulation, dual engines &amp; UI</em></summary>
  <br />
  <pre><code>src/
├── core/
│   ├── catalog.ts              # 11 bilingual stations, characters, hoverboards, upgrades, billboards &amp; missions
│   ├── simulation.ts           # Deterministic kinematics, coyote time, input buffer, monsoon spring physics &amp; framing
│   ├── simulation.test.ts      # Automated unit tests for physics, collisions &amp; swipe classification
│   ├── voiceOver.ts            # Kannada / Kanglish Web Speech API voice-over phrase bank &amp; voice picker
│   └── voiceOver.test.ts       # Automated unit tests for voice selection &amp; phrase rotation
├── engine/
│   ├── createRunnerEngine.ts   # Safe WebGL2 context acquisition with silent Canvas2D fallback
│   ├── MetroRunnerEngine.ts    # Full 3D Three.js engine, dynamic lighting, weather particles &amp; chase camera
│   ├── Canvas2DRunnerEngine.ts # Bespoke 2.5D perspective fallback engine for zero-black-screen resilience
│   ├── meshes.ts               # Procedural 3D rigs: runners, trains, ramps, BBMP barricades, trees &amp; stations
│   ├── textures.ts             # High-contrast CanvasTexture generator for billboards, rails &amp; bilingual signage
│   └── sound.ts                # Zero-asset procedural WebAudio synthesizer &amp; station chime engine
└── ui/
    ├── TitleScreen.tsx         # Live 3D lobby overlay with daily missions &amp; quick launch
    ├── GameHud.tsx             # Score, multiplier, station arrival banners, power-up timers &amp; voice subtitles
    ├── ShopSheet.tsx           # Character roster, hoverboard garage &amp; 5-tier upgrade deck
    ├── Modals.tsx              # Pause, settings (quality/audio/touch pad) &amp; witty Bengaluru run summary
    └── ErrorBoundary.tsx       # Graceful UI recovery boundary</code></pre>

<h2 id="quick-start">✦ Quick Start</h2>

<p>Run <strong>Namma Metro Rush</strong> locally in under 30 seconds:</p>

<pre><code># 1. Clone the repository
git clone https://github.com/vishwassrinivas7/Namma-Metro-Rush.git
cd Namma-Metro-Rush

# 2. Install dependencies
npm install

# 3. Launch the Vite dev server (http://localhost:3000)
npm run dev</code></pre>
